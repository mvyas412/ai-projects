## Shared visual specification

- Bright white 16:9 enterprise poster.
- Large navy title with a concise italic subtitle.
- Blue, teal, purple, and green rounded system boundaries.
- Compact white component cards with restrained shadows and technical icons.
- Solid navy arrows for primary runtime/data flow.
- Dashed purple arrows for authorization, metadata, audit, or feedback.
- Dashed blue/teal arrows for status, control, delivery, or telemetry.
- Exact, concise labels sourced from `ARCHITECTURE.md`.
- Phase posters use status badges; the final-state poster contains no phase
  numbers, roadmap, or implementation status.

The diagrams are explanatory raster assets, not the editable source of truth.
When a difference exists, `ARCHITECTURE.md` and accepted architecture decisions
take precedence.
